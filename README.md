# Project Title: Active Directory Homelab - Hands-on Practice

## 📌 Overview
This repository documents a hands-on Active Directory homelab built using Hyper-V.
It demonstrates core Windows system administration concepts including AD DS, DNS,
organizational unit design, group-based access control, and Group Policy.

---

## 🎯 Objectives
- Build a virtualized Windows domain environment
- Deploy Active Directory Domain Services
- Learn how to Implement AGDLP security model
- Apply and test Group Policies
- Troubleshoot issues

---

## 🖥️ Environment
- Windows Server 2025 (Domain Controller)
- Windows 11 (Client Computer)
- Hyper-V
- Active Directory Domain Services
- Group Policy Management
